# Code of Conduct

This project follows the [Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, assume good faith. Harassment,
personal attacks, and discriminatory behaviour are not tolerated.

Violations can be reported to the maintainers via the contact listed in
[SECURITY.md](SECURITY.md). All reports are handled confidentially.

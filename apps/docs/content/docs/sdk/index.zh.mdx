---
title: SDK
description: 适用于 Cloud、自托管 FishMem 与本地 Desktop CLI 的官方 TypeScript 和 Python 客户端。
---

FishMem 维护两套 HTTP SDK 与一套语言无关的 Desktop CLI 契约：

- TypeScript/JavaScript：`@fishmem/sdk`；
- 同步与异步 Python：`fishmem`；
- 两种 SDK 都可包装 `fishmem call` 本地桥接。

TypeScript HTTP 客户端只使用标准 Web API：`fetch`、`Headers`、`URL` 与 `AbortSignal`，无需平台适配器即可运行于：

- Node.js 20 及以上版本
- Bun
- Deno
- Cloudflare Workers
- Vercel Functions 与 Edge Functions
- 其他兼容 WinterCG 的 Serverless Runtime

Desktop 子路径是 Node 专用，因为它调用本地 CLI。

```bash
npm install @fishmem/sdk
pip install fishmem
```

```ts
import { FishMem } from "@fishmem/sdk";

const fishmem = new FishMem({ apiKey: process.env.FISHMEM_API_KEY! });

const { results } = await fishmem.memories.search({
  query: "这位用户偏好怎样的回答？",
  user_id: "alex",
  top_k: 5,
});
```

同一 SDK 同时支持 FishMem Cloud 与自托管的 `apps/web`；自托管时设置 `baseUrl`。

长文本和文件使用独立的 `fishmem.documents` 资源。直接文本摄取是同步的；PDF、Office、EPUB、邮件、图片与文本文件上传会进入持久化提取队列。原始文件保持为规范来源，提取后的 Markdown、分块与向量都是可重建的检索投影。

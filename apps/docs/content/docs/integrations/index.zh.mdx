---
title: 集成
description: 通过 TypeScript 或 Python SDK 把 FishMem 接入智能体框架。
---

FishMem 提供与框架无关的 TypeScript 与 Python SDK。TypeScript 包只依赖 Fetch API，可在多种运行时使用，避免框架适配器落后于宿主版本。

所有集成都遵循同一生命周期：

1. 调用模型前搜索 FishMem；
2. 只把相关结果注入模型上下文；
3. 回合结束后，用 `infer:false` 保存持久结论，或用 `infer:true` 提交原始消息并进行一次提取。

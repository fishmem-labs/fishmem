---
title: Cloud 与开源版
description: 在自行托管 FishMem 与 FishMem Cloud 之间选择。
---

FishMem 采用 open-core。开源记忆引擎与 Cloud 运行的是**同一套引擎代码**，不存在行为不同的私有引擎分叉。你选择的是谁来运营基础设施。

| | 自行托管 `fishmem` | FishMem Cloud |
| --- | --- | --- |
| 引擎 | 开源引擎 | 同一引擎与代码路径 |
| 基础设施 | 自行运营图存储、向量索引与模型 | 由 FishMem 运营 |
| 设置 | 自行配置与部署 | 创建 Key 后调用 API |
| 控制台 | `apps/web` 包含概览、Sources、记忆、请求、操作与配置 | 同一控制台加托管账单界面 |
| Key 与访问 | 内置项目级 `fm_...` Key；身份和部署自行运营 | 托管身份与项目 Key |
| 用量 | 请求日志、提供商用量、警告与健康状态；无托管额度费用 | 原子额度授权、账本、订阅与用量视图 |
| 账单 | 无 FishMem 费用，自付基础设施 | Stripe 月订阅 |
| 扩缩容与升级 | 自行负责 | FishMem 负责 |
| 许可证 | Apache-2.0 | 基于同一引擎的商业服务 |
| 支持 | 社区 | 按套餐支持 |

数据必须留在自己的账户或地区、需要网络隔离/自定义供应商，且团队能承担迁移、备份、监控和升级时选择自托管。希望快速上线、减少运维且需要托管账单与支持时选择 Cloud。两种路径都应通过真实工作负载验证召回与延迟。

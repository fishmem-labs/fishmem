FishMem Cloud 使用按月 Stripe 订阅。套餐决定每月额度容量，订阅通过控制台中的 Stripe 客户门户管理。

## 套餐

| 套餐 | 月价 |
| --- | --- |
| Hobby | 免费 |
| Starter | 19 美元 |
| Growth | 79 美元 |
| Pro | 249 美元 |
| Enterprise | 按书面需求评审 |

当前结账页面会显示所选套餐、包含额度、续订周期、币种、适用税费与可用支付方式。不要从旧文档或请求日志推算价格。

## 套餐与额度

套餐是每月额度桶，额度是稳定的操作计量单位。月度额度在账期重置；读取与列表免费。详细操作成本见[用量与额度](/zh/cloud/usage-and-credits)。开源引擎本身不计 FishMem Cloud 费用，自托管基础设施与模型费用由部署者承担。

## 管理订阅

从控制台的 Usage and billing 打开 Stripe 客户门户，可查看发票、更新付款方式或取消续订。FishMem 不接收完整卡号。取消停止后续续订，不自动退还已使用额度或删除项目数据。

## 更换套餐

升级、降级、生效时间与可能的按比例费用以 Stripe 结账或门户显示为准。余额不足时，计量写入与搜索会暂停，读取继续工作。企业容量、安全、合规或部署范围只在书面约定后成立。

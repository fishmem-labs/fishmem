---
title: 用量与额度
description: FishMem 如何用额度计量 API 操作。
---

FishMem Cloud 使用固定**额度**计量操作，套餐决定每月额度容量，控制台显示消耗。

| 操作 | 额度 |
| --- | --- |
| 推理写入 | 2 |
| 原文写入（`infer:false`） | 1 |
| 记忆搜索 | 1 |
| 直接文档写入 | 每个预计分块 1 |
| 文件提取 | 每开始 5,000,000 字节 50，再加每个预计分块 1 |
| 文档搜索 | 1 |
| 记忆读取/列表 | 免费 |
| 文档读取与删除 | 免费 |

推理写入调用一次 LLM 并只保存提炼记录；原文写入不调用 LLM。直接文档写入按确定性分块计费，响应返回准确分块数。文件提取先按原文件大小计费，Docling 产生不可变产物后再按实际投影分块计费。

## 何时结算

计量操作开始前原子预留额度。成功后结算；引擎在提交前失败则释放预留并写入退款账本。`infer:true` 在返回 HTTP `202` 前完成预留，预留以 Event ID 跨工作进程重试；`SUCCEEDED` 只结算一次，终态 `FAILED` 只退款一次。

写入使用相同 `Idempotency-Key` 关联用量与操作。安全重放返回同一事件，不会重复收费；相同 Key 配不同内容会被拒绝。中断请求遗留的过期预留会按租约恢复并退款。

异步文件有两次稳定预留：完成上传时预留大小费用；全部提取尝试在产物产生前失败则退款。不可变 Markdown/JSON 产物存在后结算提取费，再按准确分块数量授权规范 RAG 提交。

在控制台查看月度余额，并用 Requests 按调用归因。套餐价格与容量以[账单](/zh/cloud/billing)页面为准，不能从请求日志自行换算美元金额。

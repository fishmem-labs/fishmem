FishMem Cloud 是开源 [`fishmem`](https://github.com/fishmem-labs/fishmem) 引擎的托管版本。Cloud 在 REST API 后运行同一套引擎代码，因此你无需自行运营数据库、向量索引、密钥管理、计量与账单。

Cloud 在开源引擎上增加：

- 按项目限定作用域、以哈希保存的 **API Key**；
- 自动执行的**工作区隔离**；
- 带可审计账本的**用量计量与额度**；
- 记忆与来源变更的 **Webhook**；
- 可观察异步任务、来源、请求与使用量的控制台；
- 由 FishMem 运营的部署、更新与支持。

## 同一引擎，不锁定数据

Cloud 与自托管版本共享核心记忆与文档契约。你可以导出规范命名空间快照，并在自托管环境重建派生投影。选择的是由谁运营基础设施，而不是一套不同的记忆模型。

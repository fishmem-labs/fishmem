---
title: 组织与租户
description: 理解 Cloud 组织、工作区、成员关系与项目数据边界。
---

FishMem Cloud 把人类协作关系与 API 数据作用域分开：

```text
账户 -> 组织成员关系 -> 工作区/项目 -> API Key -> 资源
```

## 组织

组织管理成员与协作边界。邀请、角色变化和移除成员影响谁能在控制台操作，但不会让模型选择租户。邀请链接与验收凭据不得写入日志。

## 工作区与项目

项目是 API 数据边界。API Key 只属于一个项目；记忆、文档、实体、事件、Webhook 与用量都带项目作用域。组织成员可以获得项目的控制台权限，但项目内部仍通过 `user_id`、`agent_id` 与 `run_id` 划分应用数据。

## 个人工作区

个人工作区用于个人账户拥有的项目。把项目迁入组织前，应核对成员权限、Key 使用方、Webhook 目标与账单所有者；迁移不会改变应用的结构化作用域。

## 删除

移除成员不等于删除项目数据。项目删除是独立的持久清除操作，应先导出、确认受影响 Key 与 Webhook，并等待清除终态。账户或组织删除也必须遵循各自的数据保留与账单规则。

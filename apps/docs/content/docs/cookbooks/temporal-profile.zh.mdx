---
title: 变化中的用户画像
description: 表达当前偏好，同时保留旧事实何时有效。
---

假设用户曾住在 Lisbon，后来搬到 Berlin。

## 带时间保存证据

用户明确生效日期时，把它放进 `event_date`。来源只证明当前状态时，不要虚构历史精度。

## 明确替代

更新或推理可以让 Lisbon 记录失效、关闭其 `valid_to`，并建立 Berlin 记录。当前召回优先有效状态；历史接口保留旧窗口。更正不是删除审计记录。

## 画像保持派生

当前画像可从规范记录与来源 ID 重建。不要把画像文本当第二份不可追溯真相；投影失败不能覆盖原始记录。

## 验收场景

- 当前居住地返回 Berlin；
- Berlin 生效前的历史问题返回 Lisbon；
- “什么时候得知”使用记录时间；
- 没有精确日期时不虚构日期；
- 更正后普通搜索不再把过期事实当当前答案；
- 历史、导出与恢复仍保留完整链条。

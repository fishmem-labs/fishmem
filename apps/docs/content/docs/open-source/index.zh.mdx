FishMem 提供两个开源构建模块。

## TypeScript 引擎

`fishmem` 包直接运行在你的进程中。图存储、向量/关键词索引、嵌入模型和 LLM 都由你选择。

```ts
import { Memory } from "fishmem";

const memory = await Memory.create({
  graphStore: { provider: "memory" },
  vectorStore: { provider: "memory" },
  embedder: { provider: "mock" },
  llm: { provider: "mock" },
});

await memory.add("The user says this project uses pnpm.", {
  userId: "alex",
  infer: true,
});
```

默认的推理写入只调用一次 LLM，并且只保存提炼后的规范记录。已整理好的内容应使用 `infer: false` 按原文保存。状态与画像是可重建投影，不是平行的权威存储。

## 自托管服务

`apps/web` 把记忆服务、REST API、控制台、身份验证、异步操作与可观测性组合在一起。应用通过 [`@fishmem/sdk`](/zh/sdk) 或直接 HTTP 调用。

多个应用或用户需要共享记忆平台时使用服务；记忆只属于单个进程时使用嵌入式引擎。

## 托管云

FishMem Cloud 是商业托管部署。它增加由 FishMem 运营的基础设施与服务承诺，但使用相同的记忆模型。

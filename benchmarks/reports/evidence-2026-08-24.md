# fishmem evaluation scorecard

All rows use paired items and identical disclosed fairness configuration.

## Release decision

The quality portfolio gate passes: FishMem has statistically positive paired
deltas on two of the three required full datasets. LongMemEval `oracle` is
+4.4 points (95% CI +1.0 to +7.8), BEAM `100k` is +5.7 points (95% CI
+1.8 to +9.5), and LOCOMO categories 1–5 is a statistically significant
-3.7-point loss (95% CI -5.8 to -1.5). The loss is part of the release result,
not an excluded slice.

Claim boundaries:

- `longmemeval:oracle` is the 500-item oracle-context variant. It is not
  LongMemEval-S and cannot support a human-beating claim against the published
  LongMemEval-S human reference.
- `https://api.openai-next.com/v1` is the disclosed OpenAI-compatible provider
  endpoint used for writes, embeddings, and judges; it is not represented as
  the official OpenAI API endpoint.
- Answer generation used one isolated ChatGPT-subscription Codex call per
  item. Those calls are counted and version-pinned but excluded from estimated
  API USD.
- The quality comparison is reusable, but the process ledgers below make total
  spend and end-to-end wall-clock comparisons non-publishable. A clean isolated
  performance run is still required.
- FishMem's mean retrieved context was 9.2x mem0 on LongMemEval and 24.1x on
  BEAM. Reducing this context expansion without losing quality is the main
  retrieval-efficiency follow-up.
